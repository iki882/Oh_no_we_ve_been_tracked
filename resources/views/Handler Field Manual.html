🕵️ HANDLER FIELD MANUAL

Persiapan UMUM

Mulai dari sini. Baca 2 menit, lalu lanjut ke misi sesuai level.

🖥️ ANALYST (PC)

  • Melihat layar game.
  • Membacakan email, hasil Detector, atau daftar koneksi.
  • Menekan keputusan. Tidak punya aturan.

📘 HANDLER (kamu)

  • Memegang buku ini (kertas / laptop lain).
  • Tidak boleh melihat layar.
  • Bertanya, menghitung, memberi keputusan: BLOCK atau TRUST.

Aturan emas

  1. Jangan intip layar. Semua info lewat suara.
  2. Tanya satu hal per pertanyaan, jawaban pendek: YA / TIDAK / angka.
  3. Ulangi angka dan IP sebelum memutuskan: "Konfirmasi, 10.4.9.201, benar?"
  4. 3 keputusan salah = SYSTEM BREACHED (game over). Lebih baik tanya ulang daripada menebak.

Cek siap main

Misi 1 · Phishing Triage EASY

Cara kerja

  1. Analyst membaca email dan hasil Phishing Detector.
  2. Kamu tanya indikator di tabel satu per satu. Jawaban YA → tambah poin (bisa minus).
  3. Total ≥ → BLOCK. Lebih kecil → TRUST.

Tabel indikator

PoinTanya ke Analyst

Detector: IP REPUTATION = CLEAN / SUSPECT / BLACKLISTED · SSL = VALID / MISSING / INVALID · DOMAIN AGE = NEW (<30 hari) / YOUNG / ESTABLISHED.

Penghitung

Contoh: domain NEW (+2), IP BLACKLISTED (+2), tiruan brand (+2), tenggat mendesak (+1) = 7 → BLOCK.
Salah yang sering: lupa poin minus (domain nusatech.co.id PERSIS, IP CLEAN, domain ESTABLISHED). Email asli bisa total di bawah 0.

Misi 2 · Firewall Breach EASY · 5 koneksi

Cara kerja

  1. Analyst membaca ID, IP, dan warna Type tiap koneksi.
  2. Cari warna di kartu → ambil aksi dasar.
  3. Lihat dua angka pertama IP (10.4.x.x). Ada di daftar PENGECUALIAN? → balik aksinya (BLOCK ⇄ TRUST).

Kalkulator

Contoh: RED + 203.0.113.45 → dasar BLOCK, 203.0 ada di pengecualian RED → TRUST.
Awas: 91.200 ≠ 91.20. Minta Analyst mengulang IP kalau ragu.

Misi 3 · Spear Phishing HARD

Apa yang beda di Hard

  • Waktu 02:30, jauh lebih singkat. Jangan bertele-tele.
  • Spear phishing: email menyebut nama / jabatan, kelihatan meyakinkan.
  • CEO fraud: pengirim meniru atasan. Poin −3 hanya jika domain PERSIS nusatech.co.id.
  • Link HTTPS dibajak: https:// bukan tanda aman. Andalkan Detector (age, IP, SSL).

Urutan tanya cepat

  1. Domain pengirim PERSIS nusatech.co.id? (−3)
  2. Detector: DOMAIN AGE, IP REPUTATION (±2)
  3. Tiruan brand / minta password, uang, file? (+2)
  4. Sisanya: http, SSL, tenggat (+1)

Pakai tabel poin yang sama dengan Misi 1. Batas tetap ≥ = BLOCK.

Penghitung

Strategi tim: Analyst langsung membaca semua hasil Detector tanpa ditanya, Handler mencatat poin sambil mendengarkan.
